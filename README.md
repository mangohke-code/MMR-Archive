# M.M.R. Archive

승리의 여신: 니케(GODDESS OF VICTORY: NIKKE)의 픽업 기록, 유니크 코스튬, 미실장 캐릭터,
기념품, 솔로 레이드, 스테이지 정보를 모아 둔 **비공식 팬 사이트**입니다.

**https://mangohke-code.github.io/MMR-Archive/**

---

## 저작권 고지

**이 프로젝트는 SHIFT UP CORP. 및 Level Infinite 와 아무런 제휴 관계가 없으며, 승인받거나
후원받지 않았습니다.**

이 저장소와 사이트에 포함된 게임 내 이미지, 캐릭터, 명칭, 대사, 애니메이션 데이터 등 모든
게임 리소스의 저작권은 **SHIFT UP CORP.** 및 **Level Infinite** 에 있습니다. 해당 자료는
팬 사이트로서 정보 제공 목적으로만 사용하며, 이 프로젝트는 그에 대한 어떠한 권리도 주장하지
않습니다.

**저작권자 또는 정당한 권리자의 요청이 있을 경우, 해당 자료를 즉시 삭제합니다.**
요청은 아래 이슈 트래커로 남겨 주시면 확인 후 처리하겠습니다.

> https://github.com/mangohke-code/MMR-Archive/issues
